# 对话提问目录

目录只展示用户消息的简短预览，不把思考、工具输出或监控唤醒通知混进目录。普通聊天、TUI、Vibot 及其嵌入的 coding 会话使用相同交互。

目录按提问顺序倒序显示：最新提问在最上方，编号保留原来的先后关系（例如 180、179、178）。搜索结果同样倒序；这只影响目录展示，不改变聊天正文、分页顺序或跳转目标。

- 对话左侧留白足够时，目录常驻展开，上沿对齐标题栏下缘，下沿停在输入区上方，不再受 500px 高度限制，也不因移开鼠标、点击正文或跳转而收起。输入框、附件或待处理请求区域增高时，目录自动缩短；长目录在自身列表内独立滚动。
- 留白不足时，目录改为与 Todo / Monitors 同级的任务区下拉菜单：优先放在可见的右侧任务栏；任务栏隐藏或被文件/终端替代时，放在输入框上方的任务区域。不再占用对话边缘。
- 下拉菜单默认向下展开，下方空间不足时自动向上；菜单通过 portal 避免被任务栏的滚动容器裁剪。支持搜索、当前提问标记、Escape 关闭、键盘操作和减少动态效果偏好。
- 点击某项后按需加载历史，跳转并短暂突出显示对应提问。相同文字的多次提问按消息 ID 区分。跳转后暂停自动跟随输出，使用“回到最新消息”恢复。

## 历史与性能

`GET /api/sessions/:id/outline?cursor=...` 复用消息接口的可见性检查与各 agent 的原生/归一化读取路径，每次返回当前页的用户消息 ID、时间和最多 180 字的预览，不返回工具结果和附件路径。响应标记为 `private, no-store`。

宽屏常驻目录自动逐页补全更早索引，窄屏仍在下拉菜单打开时才读取；目录隐藏或切换会话会中止索引读取，已读条目保留到本次会话视图关闭。很长的索引分批读取，可继续加载。跳转才读取所需的完整历史页，遇到网络失败保留已知条目并提供重试。取消跳转、切换账号/agent 后不再把过期请求用于新视图。

深层跳转保持最多 600 个消息块的渲染窗口，避免因为选择很早的问题就挂载整段巨大 DOM；原有手动“渲染剩余消息”仍是用户明确选择的操作。目录读取和定位不改写原生对话、不唤醒模型、不修改 Todo 或 Monitor。
