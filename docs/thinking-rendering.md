# Thinking Markdown 渲染

普通聊天与 TUI 的 thinking 内容复用正文的 Markdown 渲染器，Vibot 也使用相同的块组件。标题、列表、强调、引用、表格、链接、代码高亮/复制和数学公式的行为与正文一致；原始 HTML 不执行，危险链接沿用既有 URL 过滤。

Thinking 保留较小、较淡的正文样式，但不再对整段文本强制 `pre-wrap` 或斜体，以免破坏 Markdown 段落、强调和代码格式。只改变展示，不修改归一化 transcript、原始 thinking 文本或厂商签名字段。

原有交互保留：输出时自动展开并显示最新内容，流式预览高度最多 7rem；结束后自动收起，手动展开/收起优先。历史 thinking 默认折叠，展开后可查看完整内容。内容尺寸变化也会更新预览滚动位置，适应公式、代码或字体加载引起的排版变化。

这是纯前端修改，构建与验证后只发布静态资源，不重启 Vibe 服务。

验证记录（2026-09-11）：typecheck、生产构建及全套 652 项回归复测通过。Chromium / Firefox × 普通 / TUI × 编码会话 / Vibot 共八组浏览器场景通过，覆盖 Markdown 结构、代码复制、公式、安全 HTML/链接处理、空内容、自动折叠、手动覆盖、流式末行追踪和窄屏布局。一次既有监控恢复用例在全量运行中未通过，单独检查和全套复测通过；仅补充了测试失败诊断，未改生产监控逻辑。前端资源已原子发布，本地与公网健康检查均为 200，服务 PID 与激活时间保持不变。
